# Baithak

A Dishoom-inspired guest site for **Baithak** — an imaginary Nepali restaurant & hotel dining room on Phewa Lakeside, Pokhara.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- Framer Motion
- Local content modules in `src/content/`

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

| Route | Purpose |
|-------|---------|
| `/` | Full-bleed hero + editorial home |
| `/menus` · `/menus/[slug]` | Nepali menus |
| `/our-place` | Lakeside location & story |
| `/reservations` | Booking form (client-only) |
| `/stories` · `/stories/[slug]` | Journal |
| `/gifts` | Static gifts catalog |
| `/careers` | Team & roles |
| `/privacy` · `/accessibility` | Stubs |
